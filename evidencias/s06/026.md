# HDU-026 · 28/10/2026

Las dos APIs ya se recolectan desde Prometheus 3.15.1 y Grafana 13.3.0 puede consultar esa fuente. Java usa Actuator y el registro Prometheus de Micrometer, con las versiones gestionadas por Spring Boot 4.1.2. Se expusieron `health,prometheus` y se activó `management.metrics.distribution.percentiles-histogram.http.server.requests=true`.

| Comprobación real | Resultado |
|---|---|
| Build Java con Actuator y Micrometer | `BUILD SUCCESS`; `/health` y `/actuator/prometheus` → 200 |
| GET Java `/patients/1` y `/patients/999999` | 200 y 404; `http_server_requests_seconds_count` pasó de 1 a 2 para cada status |
| Histograma Java | Buckets presentes para ambos status con `uri="/patients/{id}"`; ninguna etiqueta contiene los ids concretos |
| Regresión del verificador FastAPI | Contador y count del histograma aumentaron exactamente uno por status; buckets y ruta normalizada correctos |
| Configuración Prometheus | `promtool check config` terminó correctamente |
| Targets y series | Python y Java `UP`; etiquetas `service="fastapi"` y `service="springboot"` en los targets y en las series consultadas |
| Grafana, comprobación en navegador | Inicio de sesión correcto; clic real en **Save & test** mostró “Successfully queried the Prometheus API.” |

Prometheus consulta `http://python-api:8000/metrics` y `http://java-api:8080/actuator/prometheus` cada 15 segundos. Son nombres de servicio de Compose; ningún target usa `localhost` dentro del contenedor. Grafana consulta `http://prometheus:9090` mediante su datasource provisionado, con uid `prometheus`. Los puertos publicados quedan en `127.0.0.1:9090` y `127.0.0.1:3000`.

Las imágenes oficiales están fijadas por versión y digest de su índice:

- `prom/prometheus:v3.15.1@sha256:fa3302279710be2f21a8301ec17a8b4f2301fd829bd113839b3b6b02b6f191a2`
- `grafana/grafana:13.3.0@sha256:488984b716c0862639f91a698adbe2862677a5a07bad42da5f03f3030883b205`

Grafana tiene usuario local `admin`, contraseña aleatoria nueva en `.env`, registro de usuarios desactivado y acceso anónimo desactivado. El secreto no se incluye en Git ni en estas evidencias. `.env.example` contiene la variable vacía y Compose exige completarla. Prometheus y Grafana usan volúmenes propios para conservar sus datos.

Se ejecutó `docker compose up -d --build --no-deps java-api prometheus grafana`: solo se reconstruyó Java y se crearon los dos servicios de observabilidad. Las pruebas HTTP fueron de lectura y no modificaron pacientes.

Para repetir desde `codigo/`, sin peticiones simultáneas a esos dos ids mientras se compara el contador:

```powershell

```
