    ¿Qué es RAG?

    RAG significa generación aumentada por recuperación: antes de responder, se buscan fragmentos relevantes de la historia del paciente y se entregan al modelo como contexto. Si esos documentos no contienen la respuesta, puede indicar que no hay información suficiente.
